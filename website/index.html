FAQ

Questions, answered

Everything people usually ask before installing.

Does my audio get uploaded to the cloud?
No. Transcription (Whisper) and speaker diarization (PyAnnote) run entirely on your machine. Only optional features — AI summaries and the chatbot LLM — call external APIs, and those only send text, never audio.
Does it join my meetings as a bot?
Never. FloatNote listens through your microphone and reads your screen locally. It works with Zoom, Meet, Teams, or any app — because it doesn't need to integrate with any of them.
What can the meeting chatbot answer?
Anything grounded in your meeting history: "What were the action items from Monday?", "What deadline did the client mention?", "Summarize what Speaker 01 said about the budget." Answers come from a local vector index of your transcripts.
Which platforms are supported?
Windows 10/11 today. The stack is cross-platform (Python + Electron), and macOS/Linux builds are on the roadmap. You can also run it from source on any OS right now.
Is it really free?
Yes — FloatNote is fully open source. Download the app or clone the repository and run it from source. Optional cloud AI features use free-tier API keys you control.
